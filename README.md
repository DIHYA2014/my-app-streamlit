# TP Machine Learning : régression et Perceptron

Application Streamlit (TP1 régression linéaire, TP2 Perceptron) avec les jeux Iris et Diabetes de Scikit-learn.

## Lancer en local
```
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Les données sont chargées depuis `diabetes.csv` pour le TP1 et `iris.csv`
pour le TP2. Les deux fichiers sont placés à la racine du projet.

## Déployer sur Streamlit Community Cloud
1. Crée un dépôt GitHub public et pousse ces fichiers à la racine : `streamlit_app.py`, `contenu.py`, `requirements.txt`, `.streamlit/config.toml`.
2. Va sur https://share.streamlit.io et connecte-toi avec GitHub.
3. Clique sur « Create app », choisis ton dépôt, la branche `main` et le fichier principal `streamlit_app.py`.
4. Clique sur « Deploy » : l'application est en ligne en quelques minutes, avec un lien à partager.
